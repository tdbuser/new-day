# NEW DAY — стартовая рабочая копия

Это отдельная копия исходного приложения Oila rejasi V2.0 с минимальным изменением названия на NEW DAY / Yangi kun / Новый день и указанием владельца. Исходный файл сохранён отдельно и не изменён.

## Важно
- Это НЕ готовая production-версия NEW DAY.
- Firebase-конфигурация оставлена пустой; при таком состоянии приложение работает в демонстрационном локальном режиме.
- Google-вход, семейная облачная синхронизация, новые разделы, награды, календарь и праздничная студия ещё не подключены/не реализованы в этой копии.
- Не переключайте QR-код, is.gd/Uycha или GitHub Pages `/door/` на эту версию.
- Не добавляйте GitHub API-токены или секреты в публичный HTML.
